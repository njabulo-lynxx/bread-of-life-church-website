# Bread of Life Church Website

A simple church website created to provide an online presence for Bread of Life Church and make important church information accessible to visitors.

## Overview

The Bread of Life Church Website is a front-end web development project focused on creating a clean, accessible, and professional website for a church.

The project was created as an opportunity to practise modern HTML, CSS, and JavaScript while designing a website around a real-world organisation.

## Features

* Church information and introduction
* Church services and activities
* Responsive website layout
* Navigation between website sections
* Clear presentation of church content
* Mobile-friendly design

## Technologies Used

* HTML5
* CSS3
* JavaScript

## Project Goals

The main goals of this project were to:

* Practise building a website from scratch
* Improve HTML structure and semantics
* Develop stronger CSS layout and responsive design skills
* Use JavaScript where appropriate
* Create a professional and user-friendly interface
* Gain experience designing a website for a real-world organisation

## Design

The website focuses on simplicity, readability, and ease of navigation.

The design was created to present church information clearly without unnecessarily complicated layouts or interactions.
